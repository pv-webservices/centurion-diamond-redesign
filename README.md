# Centurion Diamond - Award-Winning Luxury Website

**100 facets. engineered to shine.**

A revolutionary 100-facet cut designed to unlock extraordinary brilliance and fire. This is a complete redesign of the Centurion Diamond website using award-winning UI/UX principles inspired by Zera Software Studio.

## 🚀 Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Typography:** Geist Sans + Inter
- **Icons:** Lucide React
- **Hosting:** Vercel (recommended)

## ✨ Features

- **Award-winning UI/UX** - Inspired by Zera Software Studio
- **Smooth scroll animations** - Framer Motion powered
- **Premium dark theme** - Black (#0A0A0A) + Gold (#E0A045)
- **Responsive design** - Mobile-first approach
- **SEO optimized** - Next.js metadata API
- **Performance optimized** - <2s LCP target
- **Premium imagery** - AI-generated luxury diamond photography

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/pv-webservices/centurion-diamond-redesign.git
cd centurion-diamond-redesign

# Install dependencies
npm install

# Run development server
npm run dev

# Open http://localhost:3000
```

## 🎨 Design System

### Colors

```typescript
background: '#0A0A0A'      // Near-black background
surface: '#0D0D0D'         // Slightly lighter surface
border: '#262626'          // Subtle borders
gold-500: '#E0A045'        // Primary accent color
```

### Typography

- **Headings:** Geist Sans (700-800 weight)
- **Body:** Inter (400 weight)
- **Sizes:** 48-64px (H1), 32-40px (H2), 16-18px (Body)

### Animations

- **Fade-up:** 0.8s cubic-bezier(0.22, 1, 0.36, 1)
- **Stagger:** 0.1s delay between elements
- **Hover:** Scale 1.02-1.05 with smooth transitions
